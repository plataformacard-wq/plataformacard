# 🏷️ Logos Oficiais da Marca (`public/assets/landing-page/logos/`)

Esta pasta armazena os arquivos vetorizados e imagens transparentes da logomarca **PlataformaShop** utilizados no Header, Footer e relatórios.

---

## 📌 Arquivos Esperados:

1. `logo_dark.png` (ou `logo_fundo_escuro_ps.png`)
   - **Descrição:** Logo oficial com texto e símbolo em tom claro/branco para aplicação sobre fundos escuros (`#0a0a0a` / `#000000`).
   - **Uso:** Header e Footer em Dark Mode.

2. `logo_light.png`
   - **Descrição:** Logo oficial com texto e símbolo escuros otimizada para aplicação sobre fundos brancos/claros.
   - **Uso:** Header em Light Mode.

3. `favicon.ico` / `icone_ps.png`
   - **Descrição:** Ícone de marca quadrado (512x512px) para uso em favicons e notificações.

---

## 📐 Especificações Técnicas:
- **Proporção:** 4:1 (ex: 400x100px)
- **Fundo:** Transparente (PNG / SVG)
