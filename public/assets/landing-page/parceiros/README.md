# 🏢 Marcas Parceiras / Marquee (`public/assets/landing-page/parceiros/`)

Esta pasta armazena os arquivos de logotipo das empresas parceiras e distribuidoras que alimentam a esteira horizontal (`CompanyLogos.tsx`).

---

## 📌 Regra de Negócio do Carrossel (Marquee):
- **Mínimo de 6 Marcas:** O efeito "esteira infinita" (`marquee`) é ativado automaticamente no frontend quando houver **6 ou mais marcas** cadastradas.
- **Formato de Upload:** PNG vetorizado ou SVG com fundo transparente.

---

## 📐 Especificações Técnicas:
- **Resolução Sugerida:** 200x80px (PNG transparente com logomarca em tom neutro/monocromático)
- **Gerenciamento:** As marcas podem ser gerenciadas pelo CMS Admin na aba "Parceiros" em `/main/landing-page`.
